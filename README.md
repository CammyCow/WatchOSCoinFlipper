# WatchOSCoinFlipper
A simple Watch OS that allows you to flip a coin

Minimum Deployment for WatchOS set to 10.6. Using SceneKit as RealityKit is not supported for WatchOS.

## About

I wanted to repurpose an older Apple Watch Series 4 by adding my own applications onto. Given that I have zero iOS development experience, much less watchOS, I created this simple project to play around with the 3D SceneKit library. 

For transparency, Gen AI was most definitely used. 

## How To

Tap the screen, and the coin will flip. Uses Bool.random()
